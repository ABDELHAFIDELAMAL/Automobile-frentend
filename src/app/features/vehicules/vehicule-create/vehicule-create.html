Créer un Véhicule

L'immatriculation est obligatoire. Minimum 4 caractères. Maximum 20 caractères.
La marque est obligatoire. Minimum 2 caractères. Maximum 20 caractères.
Le modèle est obligatoire. Maximum 40 caractères. Caractères invalides détectés.
L'année est obligatoire. L'année doit être 1900 ou ultérieure. L'année ne peut pas être dans le futur.
Le kilométrage est obligatoire. Le kilométrage ne peut pas être négatif.
La sélection est obligatoire. Minimum 4 caractères. Maximum 20 caractères.
