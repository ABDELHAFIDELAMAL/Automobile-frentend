Créer une Intervention

La sélection du véhicule est obligatoire.
Le type d'intervention est obligatoire.
La description est obligatoire.
Le statut est obligatoire.
Le niveau de priorité est obligatoire.
Le coût estimé est obligatoire. Le coût ne peut pas être négatif.
La date de dépôt est obligatoire.
La date de restitution prévue est obligatoire.
La date de clôture est obligatoire.
